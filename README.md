A program that writes the single weirdest job title it can think of — "Professional Apologizer for Billionaires' Yachts", 48 characters — to `/output/entry.txt`, for make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty. A blind judge compares titles two at a time and keeps the weirder, funnier one. The title is a real-sounding job with one hilariously specific twist: a professional apologizer, except the apologies are for billionaires' yachts — as if the yacht itself did something wrong and someone has to say sorry for it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Writes exactly the 48-character title, nothing else. Deterministic, no network, stdlib only. The program clears only the output directory's contents, never the directory itself.
